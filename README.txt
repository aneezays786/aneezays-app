ANEezay's Clothing App
=======================

FILES
-----
index.html  -> app structure
style.css   -> aesthetic design
app.js      -> products, filters, cart, wishlist button and product modal

HOW TO RUN
----------
1. Keep all 3 files in the same folder.
2. Double-click index.html.
3. The app opens in your browser.
4. Products/cart work without a server.

IMPORTANT
---------
The product images in this starter version are aesthetic placeholders made with CSS.
Replace the .product-img backgrounds with your own clothing photos when ready.

NEXT STEPS FOR A REAL STORE
---------------------------
- Add real product photos
- Add your WhatsApp/business contact
- Add a real checkout/order form
- Connect a database for products/orders
- Add secure payment processing
